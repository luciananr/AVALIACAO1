# AVALIACAO1

Este repositório contém implementações de diferentes programas em C# desenvolvidos como parte de uma avaliação. Os programas abordam conceitos básicos de lógica de programação, manipulação de listas, validação de entradas e jogos interativos.

## Programas Incluídos

### 1. **Jogo da Forca**
- **Descrição**: Um jogo interativo onde o usuário deve adivinhar uma palavra letra por letra. O programa fornece uma dica para ajudar o jogador.
- **Funcionalidades**:
  - Seleção aleatória de palavras com dicas.
  - Exibição da palavra oculta com underscores (`_`).
  - Controle de tentativas restantes.
  - Mensagens de vitória ou derrota.
- **Como executar**:
  - Navegue até o diretório `FORCA` e execute o programa:
    ```bash
    dotnet run
    ```

### 2. **Cálculo de Média**
- **Descrição**: Um programa que lê nomes e notas de alunos, calcula a média da turma e exibe os alunos com notas acima da média.
- **Funcionalidades**:
  - Validação de entradas (nomes não podem ser nulos ou vazios, e notas devem ser numéricas).
  - Cálculo da média da turma.
  - Exibição de alunos com notas acima da média.
- **Como executar**:
  - Navegue até o diretório `MEDIA` e execute o programa:
    ```bash
    dotnet run
    ```

### 3. **Jogo de Adivinhação**
- **Descrição**: Um jogo onde o usuário tenta adivinhar um número secreto entre 1 e 1000.
- **Funcionalidades**:
  - Geração de número aleatório.
  - Feedback sobre a proximidade da tentativa (muito distante, distante, perto).
  - Mensagens de vitória ou derrota.
- **Como executar**:
  - Navegue até o diretório `ADIVINHACAO` e execute o programa:
    ```bash
    dotnet run
    ```

### 4. **Verificador de Palíndromos**
- **Descrição**: Um programa que verifica se uma palavra ou frase é um palíndromo (lê-se da mesma forma de trás para frente).
- **Funcionalidades**:
  - Ignora espaços e diferenças entre maiúsculas e minúsculas.
  - Validação de entradas.
- **Como executar**:
  - Navegue até o diretório `PALINDROMO` e execute o programa:
    ```bash
    dotnet run
    ```
